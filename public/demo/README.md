# Real demo clips — owner content only

This folder is the slot where REAL demo clips will live once the site
owner provides a video. It is intentionally empty right now.

Rules (ClipForge Phase 10 — "no demo, real only"):

- Nothing here is generated, synthesized, stock, or borrowed. A clip
  in this folder must be a real clip rendered by this tool from a
  video the owner recorded or owns the rights to.
- No placeholder videos, no drawings, no fake captions. Until the
  owner sends a video, the homepage shows no demo clips at all — it
  shows the working tool instead (see the "See it work" section).
- To add real clips later: the owner sends a short video → the team
  renders real clips with the tool → the real clip files land here
  with a `clips.json` manifest (title + source video, in plain
  words) → the homepage gains a "Real clips" section that plays
  them. No other content is ever placed here.
